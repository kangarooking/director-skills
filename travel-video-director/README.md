# AI 文旅导演（计划中）

`travel-video-director` 将是 `director-skills` 的第一个专项 Skill，目标是把文旅宣传需求转换为可实际执行和验收的 AI 视频方案。

## 拟覆盖范围

- 提炼目的地卖点、受众、传播平台和观看后行动
- 选择风景叙事、人物游历、文化故事或活动预告等创意路线
- 生成时间线、解说词、分镜表和可直接使用的分段提示词
- 管理人物、地貌、建筑、服饰、光线、时间与镜头连续性
- 审查地名、历史、民俗、非遗与宗教文化表达
- 根据真实生成结果评估画面、连接段、字幕、音频和成片完整度

## 计划交付物

1. 文旅创意策略卡
2. 30–60 秒完整时间线
3. 镜头级分镜与旁白/字幕
4. 分段视频生成提示词
5. 首尾帧衔接和一致性锚点
6. 事实、文化、版权与成片验收清单

本目录只是范围说明，尚未提供 `SKILL.md`，因此不是可安装的 Skill。待真实文旅案例跑通并通过验收后，再将其标记为可用。
