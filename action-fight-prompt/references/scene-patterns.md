# 题材配方与输出样式

四类高频打戏题材的专用配方。通用四条铁律（拆段/因果/环境反馈/锁定）仍全程生效，本文只写各题材的增量规则。

## 一、载具追逐战

物理重点在"车"而不在"人"——打击感来自机械的重量与形变。

- **机械细节词**：悬挂压缩回弹、后轮剧烈打滑、重心转移压车、甩尾、轮胎碾飞碎石、车辙拖痕、车头短暂轻震、引擎轰鸣拔高/回落低鸣。
- **冲撞逻辑**：正对冲撞用车头，侧向来袭用重心转移+甩尾横扫——先写"为什么不能用上次的方式"，再写新解法，这是载具戏的因果链形态。
- **群体敌人分层**：交代数量与行为顺序（转身 → 嘶吼 → 扑出的先后必须被镜头拍清楚），主力怪压后作为下一轮伏笔。
- **环境反馈**：沙尘尾迹、弧形沙浪、地面擦痕、崩飞的碎石——高速感全靠地表被破坏的程度传达。
- 镜头：低机位斜后方跟拍（俯冲）、侧后方中景跟拍（侧扑+压车）、命中瞬间轻微减速但保持弧线/命中点/飞出方向可读。

## 二、人 vs 巨型生物（硬碰硬流）

核心是"实力差"——第一击必须失败，失败必须物理一致。

- **硬碰硬四步**：全力一击 → 接触瞬间火花巨响 → 明确结果（"没有切入、没有伤痕，只有一次强烈撞击"）→ 反作用力沿刀身传回双臂、主角失去平衡被震飞。禁写"砍进去了"。
- **后果链**：震飞 → 空中坠落 → 重摔 → 连续翻滚卸力 → 勉强单膝停住——每一步都有上一的动能来源。
- **装备损伤**：刀刃卷曲、装甲刮痕——道具被战斗改变，是最便宜的可信度。
- **心理反应一拍**：瞳孔微缩、瞬间意识到硬度远超预期——一句即可，放在撞击结果之后。
- **结尾钩子**：实力差定格（完好巨兽 vs 卷刃），铺垫"找弱点/换战术"。
- 镜头：随被震飞方向平移、下坠时轻微下压跟随——镜头追随主角的动能，不旁观。

## 三、写实群战（一镜到底）

风格约束最重的一类，前 1/4 篇幅全部用于声明规则。

- **风格开关前置**：单一连续镜头不切镜、原始手持手机质感、自然细微抖动+轻微果冻效应、不使用防抖、纪录片式真实感。
- **声音规则最严**：不要音乐。只保留真实环境音——脚步、课桌椅摩擦、衣物摩擦、击打、空调低鸣、呼吸、远处环境声。安静本身是紧张感来源。
- **光线即舞台**：真实光源逻辑（窗外自然光+室内日光灯混合），空气中可见漂浮灰尘，人物经过时打乱尘埃与光影层次。
- **对手规则**：所有对手面孔各不相同，禁止与主角相似；身份统一（如同为男高中生），外形各异。
- **效率美学**：主角动作干脆利落、无多余表演；每击一对一倒，倒地后"身体完全失去力量"；反派动作可以狼狈（踉跄、捂脸、先手连攻）制造危机感。
- **标志性瞬间**：唯一一次微慢动作（约 0.2-0.3 秒）留给最重的一击，且破坏物要给足反馈层级——撞击 → 表面物爆散 → 空中漂浮旋转 → 槽内碎块弹起落地 → 衣物留下擦痕 → 沿壁滑落瘫倒。
- **结尾情绪定格**：动作结束后留 2 秒给"人"——沉重呼吸、擦血痕迹、整理发丝、摘下身份象征物轻描淡写丢下、转身离场、画面淡出。冷漠感靠细节不靠台词。

## 四、巨型生物/机甲大场面（能量系）

体量差最大的一类，用分镜头命名式，镜头承担叙事。

- **分镜命名**：每个镜头一个动词性命名（接近 / 交战 / 蓄力 / 突击 / 余波），段落内写透单一景别。
- **景别阶梯**：贴地高速掠过（渺小感）→ 大范围环绕（体量对比）→ 中景悬停蓄力（压迫感）→ 第一人称俯冲（代入感）→ 极远航拍大全景（破坏全貌）。景别必须逐级拉开，最后一级给"极远"。
- **体量描写**：巨兽身体部位按人类结构类比（人类躯干/双臂/双腿+融合形态），攻击写"巨大的水流手臂向下挥动"而非泛写"攻击"。
- **能量蓄力段**：悬停 + 周围物理异常（雾气扭曲、水颗粒悬浮、湍流、云层增强）——力量积压用环境畸变表达，不用发光特效词。
- **余波段**：破坏后果清单（环形波纹扩散、碎块下落、湍流减弱、雾气漂移）+ 主角定帧位置 + "逐渐归于平静"收尾。
- 音效约束单独一行收尾："不要生成音乐，只生成音效"。

## 音效层写法（通用）

两种落法，选一种贯穿全文：

1. **分段式**：每阶段末尾一句"音效：……"。适合音效随动作强变化的近身戏。
2. **总述式**：结尾整段按时间顺序罗列音效节奏（"引擎轰鸣拔高 → 碎石飞溅 → …… → 回落为厚重低鸣"）。适合载具/大场面，音效本身有起伏弧线时。

必含三层：力量声（撞击闷响、引擎、破风）、材质声（碎石、摩擦、火花嗤响）、生物声（嘶吼、喘息、低鸣）。无配乐需求时必须显式写"不要音乐，只保留音效/环境音"。

## 两种输出样式骨架

**A. 时间戳式**（近身对打/追车/群战）：

```
[风格开关]
[资产锁定 + 对手规则]
[场景/光线/声音规则]
0—2秒：段落正文（镜头句式嵌入：镜头用……跟拍）
2—5秒：……
…
[音效段]
```

**B. 分镜头命名式**（大场面/能量系）：

```
[角色资产锁定 + 参考图映射]
镜头01——接近：段落正文
镜头02——交战：……
…
[收尾：不要生成音乐，只生成音效]
```
