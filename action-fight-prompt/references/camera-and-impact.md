# 运镜与打击感词库

设计时序段时按需取用。原则：镜头服务于动作，词汇服务于物理逻辑。

## 运镜词汇（按节奏阶段选用）

### 蓄力段——交代空间，制造压迫
- 缓慢推近（slow push-in）：从全景推向对峙双方，制造张力
- 低角度仰拍（low-angle）：强化怪兽/强敌的体量威胁
- 越肩镜头（over-the-shoulder）：建立双方位置关系，为后续动作交代空间
- 环绕（orbit/arcs）：慢速绕行对峙的两人

### 爆发段——贴身、快、有震动
- 贴身跟拍（tracking）：跟随冲刺或翻滚方向横移
- 手持震动（handheld shake）：撞击瞬间轻微抖动，传递冲击力
- 快速甩镜（whip pan）：借动作方向甩切，隐藏剪辑点
- 子弹时间/极速放缓（speed ramp）：关键一击瞬间降速再恢复——每段最多用一次，滥用会稀释节奏
- 特写插入（cut-in）：武器相撞、脚掌蹬地、眼神的极短特写

### 余韵段——释放与定格
- 缓慢后拉（slow pull-back）：从近景拉到全景，尘埃中看清战场
- 定帧（hold）：胜负分明的一瞬停住，配环境反馈的余波（沙粒落定、金属余音）
- 升格慢镜（slow motion）：仅用于最后一击后的余韵，不用于连续打击

**禁止**：全程固定机位；一段内运镜切换超过 2 次；无意义炫技运镜。

## 打击感写法

打击感 = 力量来源 + 接触瞬间 + 物理后果 + 环境反馈，四环缺一不可。

**弱写法**（无打击感）：`女主挥刀砍中怪兽`

**强写法**：
```
女主腰部发力带动折叠刀横斩，刀刃撞上怪兽前臂甲壳——
接触瞬间迸出火星，怪兽头部被力道带得偏转半寸，
前爪在沙地上犁出两道浅沟，尘土腾起。
```

要点：
- **力量从身体写起**：腰部发力、蹬地起跳、借冲势——不是手臂凭空挥动
- **接触要有材质反应**：金属→火星、甲壳→碎屑、沙地→犁沟、混凝土→崩裂
- **后果要有位移**：偏转半寸、后退半步、踉跄——身体被力改变了状态，这正好为下一阶段提供因果条件

## 因果衔接词库

时序段中每个阶段的动作开头，用这些词承接上一阶段的结果：

- 借势类：借助其冲势 / 顺着惯性 / 趁其重心前倾
- 后果承接类：被击中的怪兽身体前倾，女主顺势 / 刀刃卡住甲壳的瞬间，怪兽猛力甩头
- 条件类：趁尘土遮蔽视线 / 借金属残骸的反弹

**自检方法**：把相邻两阶段连起来读，若能自然填入"因为（上一阶段结果），所以（本阶段动作）"且符合物理逻辑，因果链成立；若读不通，就是孤立动作，必须改写或合并。

## 环境反馈词库（按场景材质）

| 地面/环境 | 反馈词汇 |
|---|---|
| 沙石/戈壁 | 尘土飞扬、沙石崩塌、碎石飞溅、地面裂纹蔓延 |
| 金属/废墟 | 金属撞击迸出火星、钢板凹陷震颤、残骸倾倒 |
| 废弃建筑 | 混凝土崩裂、粉尘从天花板洒落、玻璃碴散落 |
| 岩壁/山体 | 岩屑剥落、回声轰鸣、落石滚下 |

用法：放在接触瞬间之后、位移后果之前，一阶段一处即可，堆叠过多会冲淡动作主体。
