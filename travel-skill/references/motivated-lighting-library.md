## 1. 布光公式

`光源依据 + 位置与高度 + 硬软和面积 + 强度与光比 + 色温 + 作用区域 + 阴影和高光 + 空间层次 + 情绪`

先决定环境、天空、窗外和实景灯的曝光，再用主光把人物放入这个关系。补光只控制阴影密度，不成为第二个主光。

## 2. 十二个变量

| 变量 | 专业写法 | 画面作用 |
|---|---|---|
| 主光 Key | 决定方向、明暗结构和主要影子 | 建立主体形体与叙事方向 |
| 补光 Fill | 柔和、接近镜头轴线、低于主光 | 控制阴影密度；越少越戏剧化 |
| 轮廓光 Rim | 主体后侧或后上方窄光 | 将人物从背景中分离 |
| 背景光 | 局部光斑、渐变、实景灯、图案光 | 增加纵深、色彩和空间信息 |
| 光源面积 | 相对主体越大、越近，光越柔 | 决定阴影边缘软硬，不等于亮度 |
| 入射方向 | 正面、3/4 侧、正侧、逆光、顶光、底光 | 决定脸型、权力感和神秘度 |
| 光比 | 2:1 轻柔、4:1 有层次、8:1 以上偏戏剧 | 控制反差与情绪强度 |
| 色温关系 | 暖主冷辅、冷主暖实景或统一中性 | 建立时间、空间和冷暖对比 |
| 控光 | 遮扉、黑旗、蜂巢、切光、负补光 | 防止光线泄漏，让阴影可控 |
| 柔化方式 | 透射柔光、反射柔光、天花板/白墙跳光 | 让光包裹主体并保持自然肤色 |
| 高光性质 | 镜面高光、漫反射亮度、高光滚降 | 决定玻璃、金属、皮肤、水面质感 |
| 光源动机 | 太阳、天空、窗户、火焰、台灯、车灯等 | 让电影灯看起来来自故事世界 |

## 3. 决策流程

1. 从首帧寻找太阳、天空、窗、火、灯具或反射面的依据。
2. 确定环境曝光，保护雪山、云、湖面和皮肤高光。
3. 只选一个主要方向。
4. 用负补光或弱柔光控制暗侧，不平均填亮全脸。
5. 必要时加入克制轮廓或背景局部光，但保持来源合理。
6. 体积光必须同时存在光束开口与薄雾、尘埃、蒸汽或雨等介质。
7. 锁定同一镜头中的曝光、白平衡、阴影方向和色温。

## 4. 文旅常用光型

### 阴天自然光

厚云层作为巨大天然柔光箱，阴影边缘柔和；摄影机一侧轻微负补光恢复人物脸部结构。环境保持真实饱和度，不添加无依据暖金轮廓。

### 高原晴天

高角度太阳形成明确硬光，人物背侧或侧后受光；脸部由天空和地面反射轻微补亮，使用负补光控制散射。保护雪山与云层高光，阴影保留纹理。

### 破云侧光

太阳从云隙照亮地貌的一部分，亮区随云层缓慢移动，但山体结构、曝光基准和阴影方向不变。把视觉重点放在故事主体或行进方向，不让全景随机闪烁。

### 单窗人物光

大窗从人物侧前方以 3/4 角度提供柔和主光，对侧负补光；室内实景灯只建立背景层次。适合克制对话，不做棚拍式全脸美光。

### 火光

可见火焰从人物侧前方提供暖色实景主光，亮度缓慢不规则变化；弱冷环境光分离暗侧轮廓。火光不频闪、不突然换色。

### 蓝调时刻

环境由深蓝青灰天空包围，附近实景灯提供克制暖色点缀。冷暖分区清楚，人物肤色可读，不把全画面染成蓝紫色。

## 5. 视频连续性约束

```text
光源位置固定且有明确依据；阴影方向、色温和曝光连续。人物肤色自然，暗部保留纹理，高光滚降平滑，雪山、云层、湖面和实景灯不过曝。反射符合材质。光线随摄影机和主体运动保持同一空间关系，不出现无来源补光、双重硬影、随机体积光或全局曝光脉冲。
```

塑料感：删除“完美皮肤、无瑕、极致高清”，改用“真实皮肤纹理、自然漫反射、柔和高光、轻微明暗结构”。
