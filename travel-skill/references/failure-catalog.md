# 失败模式与修复

## 目录

1. 空间与内容
2. 运镜与转场
3. 人物与动作
4. 光影
5. 时间与提示词
6. 技术与风险

## 1. 空间与内容

| 症状 | 原因 | 修复 |
|---|---|---|
| 草、道路、人物突然出现 | 内容提示词新增首帧没有且无路径的元素 | 删除；或换含该元素的新首帧 |
| 山腰下一秒变贴地机位 | 摄影机在时长内物理不可达 | 缩小高度变化或拆段 |
| 地貌融化、建筑变形 | 要求模型重写场景或穿越未知空间 | 锁定几何；只描述已有元素的运动 |
| 人物中途入场像硬切 | 首帧无人物和入口 | 让人物从可见边缘/通道进入，或使用新首帧 |

## 2. 运镜与转场

| 症状 | 原因 | 修复 |
|---|---|---|
| 全景突然切特写 | 一次生成塞入多个独立景别 | 只保留单轴推进，或拆分生成 |
| 运镜漂亮但与剧情无关 | 未确定跟随对象和叙事目的 | 先写主体行为；车辆场景优先跟车 |
| 转经筒特写硬切双人镜头 | 使用“切到、独立段落”等剪辑语言 | 用单向横移/跟拍连续揭示，或正常拆镜 |
| 遮挡转场凭空生成前景 | 遮挡物不在首帧 | 仅使用已有门框、人群、车辆、墙体等 |
| 过度旋转、随机变焦 | 叠加多个主运动或风格词 | 只留一个主运镜和明确落点 |

## 3. 人物与动作

| 症状 | 原因 | 修复 |
|---|---|---|
| 脸、衣服、发型漂移 | 提示词重复改写人物，或缺少参考图 | 上传稳定参考图，只写动作和必要连续性 |
| 手部、红绳或马具变形 | 手指动作过细、交互步骤过多 | 简化为单一抓握、已有活结或分镜完成 |
| 对白没有说完 | 台词、动作和停顿超出时长 | 计算语速，删台词或在自然尾帧续写 |

## 4. 光影

| 症状 | 原因 | 修复 |
|---|---|---|
| 画面平淡 | 只写“电影感自然光” | 写出光源、方向、光比、负补光和视觉重点 |
| 四面来光/双重影子 | 多盏硬光同时充当主光 | 只留一个 Key；Fill 改柔或用 Negative fill |
| 无理由金色高光 | 套用黄金时刻词汇，无视首帧天气 | 改为场景匹配自然光 |
| 体积光像特效 | 没有雾尘介质或光束开口 | 增加真实依据，否则删除体积光 |
| 雪山、湖面爆白 | 环境曝光没有先锁定 | 保护高光，人物以反射补光塑形 |
| 皮肤塑料感 | 完美皮肤、超高清等词过多 | 保留真实纹理、自然漫反射和柔和滚降 |

## 5. 时间与提示词

| 症状 | 原因 | 修复 |
|---|---|---|
| 模型自己剪成三段 | 画面内容被写成三个独立镜头 | 时间段只描述同一空间连续状态 |
| 提示词越改越乱 | 不断增加术语和风格词 | 回到动作 + 一个主运镜的首轮版本 |
| 时空转场失败 | 地面仍可见时直接改变地点/时间 | 先让天空或合法遮挡完全占满画面，或拆镜 |
| 续写接不上 | 没记录尾帧状态 | 建立主体、机位、光线、风向与道具状态表 |

## 6. 技术与风险

- 输入前检查文字、水印、黑边、压缩、分辨率和画幅。
- 小红书、抖音、影视截图不因“去水印”而自动获得商业授权。
- 人脸、儿童、宗教仪式和民俗行为要单独提醒肖像及文化风险。
- 地名、建筑、服饰和宗教行为不确定时，不用 AI 断言；标记待核验。
