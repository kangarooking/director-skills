## 1. 运镜公式

`景别与机位 + 明确轨迹 + 速度与稳定性 + 跟随对象 + 主体动作 + 依次揭示的已有空间 + 落点 + 镜头与光线 + 单镜头约束`

母版：

```text
一个连续单镜头。[景别]，[机位高度与角度]。摄影机以[轨道/斯坦尼康/稳定器/手持/无人机]沿[明确轨迹]从[起点]移动到[终点]，速度[节奏]；始终将[主体]保持在[画面位置]。[主体动作]。运动过程中依次显露首帧中已有的[前景]、[中景]和[背景]，最终停在[明确构图]。[焦段/景深]，[有依据的光线与情绪]。运动平滑、物理合理，主体、地形、建筑、曝光和白平衡保持连续。
```

## 2. 选择顺序

1. 谁是当前故事主体？
2. 观众需要跟随、观察、发现还是离开他？
3. 首帧空间允许固定旋转还是整体移动？
4. 一个主运动能否完成叙事？
5. 终点要交给下一镜什么信息？

人物在车上时，优先跟车、车内观察或沿其视线揭示，不让摄影机脱离人物去做无关航拍。

## 3. 风险等级

### A 级：图生视频优先

- Locked-off shot 固定机位
- Slow pan / tilt 缓慢横摇或俯仰
- Slow dolly push-in / pull-out 单轴推进或后拉
- Truck left/right 小幅横移
- Follow / lead / side tracking 单一跟拍
- Rack focus 固定机位单次拉焦

### B 级：需空间支持

- 90-degree arc 小半径绕拍
- Doorway follow-through 穿门跟拍
- Crane up/down 小型摇臂
- Parallax push 有真实多层前景的视差推进
- OTS push 肩后推进

必须确认门、通道、前景和环绕空间真实存在。

### C 级：高风险

- 180/360-degree orbit
- Aerial dive / FPV fly-through
- Dolly zoom
- Macro probe pass-through
- Bullet-time orbit
- 三段以上组合长镜头

优先使用首尾帧、运动参考或拆分生成。若无支持，降级为 A/B 级。

## 4. 常用模板

### 固定观察

一个连续单镜头，摄影机完全锁定。[主体]在现有场景中完成一个明确动作；只有人物、衣物、烟雾、水面、旗帜等已有元素自然运动。画框、焦段和地平线不变。

### 跟随人物或汽车

稳定器/摄影车从主体侧后方保持恒定距离和高度，以相同速度平行跟随；主体位于三分线，近景快速掠过、远景缓慢移动，形成符合速度的真实视差。结尾随主体减速并形成稳定落点。

### 缓慢揭示

固定支点从已有空场或线索缓慢横摇，依次越过首帧中可见的环境细节，最后停在关键主体；前半段不提前暴露目标，结尾自然减速并锁定。

### 人物入场到环境揭示

最多两段：先在已有路径上跟随人物；人物停下后，摄影机小幅后拉或升高，揭示首帧空间中原本被构图边缘遮住但物理连续的环境。禁止中途切换地点或突然改变机位高度。

### 时间戳组合

组合动作最多两到三段，每段明确“看见什么”。第二段必须从第一段的摄影机状态和方向自然延续。

## 5. 稳定约束

```text
一个连续镜头，摄影机只执行上述运动；轨迹平滑、速度可控、符合惯性，地平线稳定。主体身份、服装、比例、方向与空间结构保持一致。无突然跳切、无镜头瞬移、无随机缩放、无多余环绕、无穿墙穿模、无焦点抽搐，不新增首帧不存在的地貌、道路、草木、人物或建筑。
```

高动态镜头允许有惯性的运动模糊和轻微震动，但主体必须可追踪、方向连续、构图可读。
