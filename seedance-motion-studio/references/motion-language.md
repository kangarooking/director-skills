# 运动语言库 V0.1

本文件是选择视觉表达方法的菜单，不是强制清单。每个镜头选择 1 个主运动策略，必要时加 1 个辅助策略，避免无目的地堆叠效果。

## A. 产品与界面
1. Product hero：产品作为稳定视觉中心，通过灯光、缓慢推近、旋转或材质细节建立价值感。
2. UI walkthrough：按照用户操作顺序呈现界面和结果；精确 UI 优先用真实录屏/后期。
3. Feature cards：用清晰的标题和独立视觉卡片逐项说明功能。
4. Macro detail：用微距细节展示材质、接口、结构或工艺。

## B. 信息与解释
5. Data reveal：先建立坐标与口径，再呈现数据变化和重点结论。
6. Mechanism build：从部件到系统，按因果顺序构建机制。
7. System flow：节点、连线和状态依序出现，强调方向和依赖关系。
8. Editorial collage：真实图片、文档、引文与图形组织成证据链。
9. Whiteboard build：用逐步绘制和标注控制学习节奏。

## C. 叙事与情绪
10. Character action：通过一个清楚的动作和反应传递角色状态。
11. Cinematic reveal：用遮挡解除、光线变化、空间揭示或推镜展示主体。
12. Continuous transformation：同一形状或对象自然变为下一对象，必须保持可理解的形变逻辑。
13. Rhythm montage：多个短镜头按节拍形成情绪或信息递进；不能牺牲关键内容可读性。

## D. 品牌与抽象表达
14. Kinetic typography：文字通过尺度、位置、遮罩和节拍变化成为视觉主体；精确文字建议后期排版。
15. Modular geometry：几何模块以网格、分组和秩序变化表达系统感。
16. 3D object motion：通过旋转、拆装、光照和空间运动展示物体。
17. Generative field：粒子、线场、点云和抽象流动表达复杂系统或品牌氛围。
18. Material study：玻璃、金属、织物、液体等材质通过可读的光线与运动展现。
19. Retro-digital：像素、终端、故障、扫描线等视觉语法，需有明确主题理由。
20. Brand mnemonic：围绕可重复的品牌形状、声音或运动建立记忆点。

## 选择步骤

1. 明确该镜头的信息/情绪目的。
2. 选择最直接的运动策略。
3. 写出运动起点、主要变化、终点。
4. 判断该策略是否依赖模型难以精确控制的文字或几何；必要时转为后期。
5. 检查是否与前后镜头共享视觉规律。
6. 删除只为“显得高级”而存在的无意义运动。

## 运动设计最小语法

- 主体：谁/什么在动？
- 起点：运动开始时画面是什么状态？
- 动作：主体或相机如何变化？
- 时序：先发生什么，后发生什么？
- 终点：动作在哪里结束，画面最终稳定在哪里？
- 观众注意力：这段运动要引导观众看哪里？
