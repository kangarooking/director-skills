# 叙事结构：先决定信息如何被理解

## 通用结构

- Hook：为什么观众应该继续看？
- Context：理解后续内容需要什么背景？
- Development：每一段增加了什么新信息？
- Turn / Proof：什么证据、变化或揭示使内容向前推进？
- Payoff：观众最后理解、记住或感受到什么？
- Close：是否需要品牌、行动引导或开放式结尾？

这不是强制的六幕模板。短视频可以把多个功能合并，但不能丢失理解所需的信息。

## 每个 Beat 必须回答

1. 观众此刻知道什么？
2. 这一段新增什么信息或情绪？
3. 观众应该看哪里？
4. 这一段结束后，为什么需要下一段？
5. 该信息适合用生成影像、真实素材、动态图形、文字还是旁白表达？

## 画面不是旁白的装饰

旁白说“成本下降”，画面就应展示成本变化、过程或证据，而不是随意播放一个人在办公室工作的镜头。画面应当补充、证明、具象化或有意对照旁白，而不是仅仅重复情绪形容词。

## 时长与信息密度

- 复杂动作需要留出可读时间。
- 重要数字和图表需要足够停留时间。
- 镜头时长要服务于动作完成、信息理解和剪辑节奏。
- 若旁白、画面动作和字幕在同一时段争夺注意力，应减少并行信息或拆分镜头。
- 不得仅为满足指定总时长而加入无意义的空镜。

## 不同任务的叙事优先级

产品介绍：问题 → 操作/功能 → 结果 → 价值。
新闻解说：事实 → 时间线 → 证据 → 影响 → 未知/后续。
科普解释：问题 → 直觉 → 机制 → 因果 → 证据/例子。
品牌宣传：品牌世界 → 视觉母题 → 情绪发展 → 高潮 → 记忆点。

## 叙事检查

逐个检查镜头：若删掉它，观众是否会失去重要信息、节奏、情绪或过渡功能？若不会，考虑删减或合并。镜头数量不是完整性的证明。
