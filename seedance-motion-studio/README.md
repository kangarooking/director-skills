# Seedance Motion Studio Skill — V0.1

一套面向 Seedance 2.0 的专业动态视频设计与制作工作流。它把创作需求拆解为内容研究、视觉方向、叙事节奏、参考素材映射、镜头规格、Prompt 编译、候选筛选、剪辑、质量审查和交付。

## 目录

- `SKILL.md`：主调度 Skill。
- `references/`：通用方法与质量规范。
- `modules/`：产品介绍、新闻解说、科普解释、品牌宣传四类任务模块。
- `templates/`：项目阶段交付模板。
- `examples/`：四类示范案例蓝图，不代表已调用 Seedance 生成成片。
- `tests/`：对抗式测试和验收量表。

## 重要边界

- 这是工作流 Skill，不是 Seedance 模型、官方 API 或自动渲染器。
- 只有当前运行环境提供已验证且获授权的生成入口时，才可以声称自动调用模型。
- Seedance 功能、输入方式、时长、画幅、分辨率与参数以实际使用入口为准；不要把未验证能力写成保证。
- 当前版本为 V0.1，状态为“可用”：作者已于 2026-10-20 确认完成测试。包内案例和审查报告保留原桌面推演阶段的历史记录。

## 快速开始

1. 将整个 `seedance-motion-studio` 文件夹放到所使用 Agent 支持的 Skills 目录中。
2. 确认入口文件名为 `SKILL.md`，并保留其 YAML frontmatter。
3. 在 Agent 中要求它读取 Skill，然后用一支短片验证流程。
4. 先完成创意方向、镜头清单和一条高风险镜头的试生成，再扩大生产。
5. 将真实结果、失败原因和最终验收写回项目记录。

具体安装方式取决于 Codex、Claude Code 或其他 Agent 的 Skills 规范；请按目标运行环境的当前官方说明完成安装。
