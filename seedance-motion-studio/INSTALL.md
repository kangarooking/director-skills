# 安装与启动

## 1. 安装前确认

本包是平台无关的 Skill 内容包。目标 Agent 必须支持从 `SKILL.md` 加载技能说明，或能够通过项目提示显式读取该文件。

## 2. 安装

将 `seedance-motion-studio` 文件夹整体复制到目标 Agent 的 Skills 目录。不要只复制 `SKILL.md`，否则模块和模板的相对路径将不可用。

若运行环境要求 Skill 名称与目录名一致，目录名使用：
`seedance-motion-studio`

安装完成后，在 Agent 中请求：
“请读取 seedance-motion-studio/SKILL.md，并按其中的任务路由规则工作。先不要生成视频，先帮我为一支 20 秒的产品介绍视频建立 brief、创意方向和初版镜头清单。”

## 3. Seedance 连接方式

Skill 本身不会授予 Seedance 使用权限。用户需通过自己可用的 Seedance 产品入口或其他已授权工具完成生成。若当前 Agent 具备经过验证的浏览器操作或 API 工具，可在确认权限、可用性和用户授权后使用；否则输出可复制的 Prompt Card，由用户手动生成并回填候选文件。

## 4. 推荐的第一次验证

- 选择一个 15–30 秒、素材清晰、风险较低的产品或品牌项目。
- 先完成 brief、方向选择、shot list 和 asset manifest。
- 只生成最难的一个镜头进行试验。
- 记录生成输入、结果、失败原因和选片理由。
- 通过 Gate C 后再批量生成。

## 5. 安装成功的判定

Agent 能够：
- 读取主 Skill 和对应模块；
- 正确识别四类任务之一；
- 生成结构化阶段交付物；
- 对参考素材明确分配职责；
- 输出结构化 Prompt Card，而不是直接写一段泛化长提示词；
- 区分建议、实际生成结果和未验证能力。
