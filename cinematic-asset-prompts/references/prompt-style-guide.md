# 资产提示词构造规范（Prompt Style Guide）

从高质量实战案例中提炼的构造规范。生成任何 prompt 时遵循本规范的结构与手法；内容必须按当次剧本/设定推导，禁止套用示例中的具体角色、配色或文案。

## 一、七段式结构（推荐骨架）

一条成熟资产 prompt 按以下顺序组织，段与段之间自然衔接为连贯段落：

1. **风格定调句**（开头第一句）：流派 + 风格标签 + 渲染质感。例式："东方末世科幻，废土机能风 + 未来工业科技装备混搭，灵笼系国创3D动画感，半写实高级建模质感。"全资产共享这一句的关键词。
2. **主体声明**：资产类型（原创人物 / 单一道具 / 载具 / 机器人 / 群像角色）+ 身份定位 + 设计年代/世界观锚点。
3. **结构分解**：按"整体→局部"逐项描述。角色按 气质→骨相→五官→身材→服装→佩挂；道具/载具按 整体形态→分区结构→材质→纹样细节。
4. **配色系统**：显式列出主色序列（如 枪灰/钛银/石墨黑/灰白）。同一 IP 内多资产必须声明共享配色与设计语言（"车体与女主装备共享……配色""采用与 XX 一致的设计语言"）。
5. **旧化与使用痕迹**：写实资产必须写服役痕迹——沙尘、划痕、边缘掉漆、维修补丁、热变色，并限定强度（"大量但克制"）。
6. **负面约束**：用中文正面否定句写进 prompt，不用后缀参数。三类必写：
   - 风格排除："不是 Tron""不是赛博朋克""无发光霓虹""无蓝色灯带""不网红脸、不幼态、不浓妆"
   - 内容排除："不参考任何真实人物、明星、网红或影视角色""禁止任何文字"
   - 比例排除："不采用夸张机甲或高达式比例"
7. **英文固定后缀块**：资产类型词 + 视角 + 背景 + 灯光 + 画质词 + `--ar`。见下表。

## 二、资产类型 × 视角 × 画幅速查

| 资产类型 | 后缀关键词 | 视角 | 画幅 |
|---|---|---|---|
| 角色全身定妆 | Character sheet, Full body shot, Standing, Front view, Neutral expression | 正面全身 | --ar 9:16 |
| 角色半身定妆 | half-body portrait, looking at camera | 半身构图 | 按需 |
| 非人形角色（机器人等） | Robot asset sheet, Full body, Standing, Front view, neutral pose | 正面全身 | --ar 9:16 |
| 载具 | Vehicle design, isolated asset | 纯侧视 (pure side view) | --ar 16:9 |
| 道具 | Prop asset, front orthographic view | 正交视图；成对道具可"一正一侧或正面+轻微3/4角度" | --ar 1:1 |
| 场景空镜 | Empty scene, panoramic view, wide angle | 全景广角 | --ar 16:9 |

背景词统一为：pure/纯灰摄影棚背景、pure neutral gray background、纯净浅灰背景——保证资产可抠图、可建模参考。

## 三、质感与灯光词库（按风格选配）

- **3D 动画质感**：半写实高级建模质感、PBR hard surface materials、industrial concept design、cinematic studio lighting、high-end Chinese sci-fi 3D animation aesthetic
- **真人写实质感**：真实皮肤纹理、毛孔自然、发丝清晰、50mm lens、natural perspective、high dynamic range、subtle cinematic contrast、真实织物材质
- **手绘动画质感**（风格化后缀，整块附加）：水墨/水粉手绘动画质感、传统矿物颜料色彩、柔和的手绘边缘扩散、不完美的笔触轮廓、动画电影颗粒
- **工业产品感**（机械/机器人）：industrial product lighting、highly detailed mechanical design、工业级关节结构/液压执行器/线缆保护组件
- 风格化后缀块可以整体嫁接：写实内容 + 手绘美学后缀，形成"内容写实 + 风格复古"的组合。

## 四、比例与可信度锚定手法

- 用现实参照物锚定尺寸与机械逻辑："以现实大排量重机车作为机械逻辑基础""接近成年人高度"。
- 机械体强调可信性关键词：批量制造、可靠性、资源效率、维护接口、模块化、快修逻辑。
- 非仿真人形需声明"人形基础结构但明显不是仿真人类，头部为传感器模块而非人脸"。

## 五、五官构造逻辑（角色/半身特写用）

- 面部按"骨相 → 比例 → 五官主次 → 表情 → 发型 → 妆容"顺序逐项写实。
- 记忆点控制：**"一个强项，两个辅助"**——只给一个主要记忆点（如眼睛），其余五官作为辅助弱化，保证"有辨识度但不过度夸张"。
- 表情一律克制："自然安静、放松，无明显笑意""不刻意卖甜"。
- 皮肤与妆面：保留毛孔细纹与真实肤质、素颜感或极淡妆、低饱和唇色。

## 六、镜头质感分层

- 后缀中的镜头词从 STEP 1 视觉方案推导：胶片感（35mm）、人像定妆（50mm/85mm）、建筑大场面（24mm 广角）。
- 灯光词全资产统一，仅角色与道具可按材质需要换用 industrial product lighting / 柔和均匀主光，但色温与调性不破。
